# 스케치 싱킹 (Sketch Thinking)

> 듣고, 그리고, 남기는 비주얼 노트테이킹 — HR 성인 학습 프로그램

Mike Rohde의 『The Sketchnote Handbook』과 『The Sketchnote Workbook』을 바탕으로, 핸드북의 개념과 워크북의 실습을 **11개 챕터**로 묶은 인터랙티브 사이트입니다. 참가자가 각 챕터의 실습을 올리면 **모두의 결과가 차트·히트맵·갤러리로 실시간 공유**됩니다.

## 챕터 구성

| 장 | 챕터 | 핸드북 | 워크북 |
|---|---|---|---|
| 1 | 스케치노트란 | 1·2장 | 1장 |
| 2 | 듣기의 기술 | 3장 | 1장 |
| 3 | 기본 요소와 드로잉 | 7장 | 1장 |
| 4 | 프로세스(준비·캡처·마무리) | 4장 | 1·9장 |
| 5 | 구조·패턴·위계 | 5·6장 | 1장 |
| 6 | 아이디어 발상 | – | 2장 |
| 7 | 아이디어 맵핑 | – | 3장 |
| 8 | 계획 | – | 4장 |
| 9 | 문서화 | – | 5장 |
| 10 | 경험 기록(여행·음식·미디어) | – | 6~8장 |
| 11 | 고급 기법·실천 약속 | 7장 | 9장 |

각 챕터 = **배우기**(개념 + 직접 그린 도해) → **실습하기**(슬라이더·선택·그리기·마인드맵·프로세스·할 일 보드 등) → **함께 보기**(레이더·막대·도넛·산점도·히트맵·포스트잇·단어구름·그림 갤러리·마인드맵 전시·별점 평가).

## 사용법

정적 사이트입니다. GitHub Pages(Settings → Pages → Branch: `main` / root)로 게시하면 바로 열립니다.

- `?room=HR2026` 처럼 주소에 방 코드를 붙이면 반별로 결과가 분리됩니다.
- `#/room` 화면에서 참가자 수, 챕터별 제출 현황, 초대 링크 복사를 할 수 있습니다.

## 실시간 공유 켜기 (Firebase, 무료 요금제로 충분)

기본값은 **단독 모드**(이 브라우저에만 저장, 샘플 참가자 12명 표시)입니다. 여러 사람이 같은 결과를 보려면:

1. <https://console.firebase.google.com> 에서 프로젝트 생성 → **Realtime Database** 만들기.
2. **Rules** 탭에 아래를 붙여 넣고 게시합니다.
   ```json
   {
     "rules": {
       "sketch-thinking": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }
   ```
   (로그인 없이 수업 중 빠르게 쓰기 위한 공개 규칙입니다. 수업이 끝나면 방을 비우거나 규칙을 `false`로 바꾸세요. 개인정보·민감정보는 입력하지 않도록 안내해 주세요.)
3. 데이터베이스 주소(`https://…firebasedatabase.app`)를 `config.js`의 `firebaseUrl`에 넣고 저장·푸시합니다.

별도 SDK 없이 Firebase REST + Server-Sent Events 로 동작합니다.

## 개발·테스트

- 외부 라이브러리 없이 순수 HTML/CSS/JS. 폰트(Gaegu, Noto Sans KR)만 Google Fonts에서 불러옵니다.
- `node tests/mock-firebase.js 9099` 로 가짜 Firebase 서버를 띄워 실시간 동작을 로컬에서 시험할 수 있습니다 (`config.js`의 `firebaseUrl`을 `http://localhost:9099` 로).
